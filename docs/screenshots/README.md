# 系统运行截图

本目录是系统实际运行时的界面截图，均由无头浏览器访问真实运行中的前后端服务采集，
可直接用于毕业论文第 5 章「系统实现」与答辩 PPT。

采集环境：Windows 11 + JDK 17 + MySQL 8.0.39 + Edge（Chromium 内核），后端 8080、前端 5173。
截图统一压缩到 1280px 宽，原始分辨率下未做任何界面调整（系统真实样式）。

## 复现方式

1. 按根目录 `README.md` 第 4 节启动后端与前端；
2. 执行 `sql/01_schema.sql` 与 `sql/02_data.sql` 恢复示范数据；
3. 以 `admin / 123456` 登录后可看到除「取件码自助查询」外的全部界面
   （该页为免登录页面，直接访问 `/query` 即可）。

> 注：截图中的数据来自初始化脚本，`今日入库`、`逾期件` 等与时间相关的指标会随执行日期变化。
